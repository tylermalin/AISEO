# Measured, Not Ranked

An interactive field guide to AI search optimization (GEO / AEO), as of November 9, 2026.

It covers how AI answer engines choose what to cite, what the evidence says works and what it says wastes the budget, how to set crawler access, how to measure presence, and a 90-day plan with hard dates. Every figure links to its source.

## What's inside

- Six sourced exhibits: Seer CTR curves, Ahrefs citation-rank share, Ahrefs brand-signal correlations, GEO paper results by method and by rank, clicks for cited versus uncited brands, and a study comparison.
- Six tools: a click-exposure calculator, a robots.txt policy builder, a citability checker, a presence tracker, a decision-rule picker, and a 90-day checklist that saves in the browser.

## Running it

It is a single static file. Open `index.html` in a browser, or serve the repo with GitHub Pages from the root of `main`. `Measured, Not Ranked.html` is an identical copy, kept so existing links still work.
